# Kannada-MNIST CNN

## Project Overview
This project focuses on classifying Kannada handwritten digits (0–9) using a Convolutional Neural Network (CNN) as part of the CBL Deep Learning assignment, Problem Statement PS-41.

## Dataset
The project uses the Kannada-MNIST dataset. The Dig-MNIST dataset is intended for evaluating generalization to handwritten digits from a different data distribution.

## Methodology
- Load and preprocess the handwritten digit images.
- Explore the dataset and visualize sample images and class distribution.
- Train a CNN model to classify digits from 0 to 9.
- Evaluate the model using appropriate classification metrics and visualizations.
- Analyze performance differences on Dig-MNIST as evidence of potential domain shift.
